# YouTube Viral Finder 🔥

バイラル動画発見ツール - チャンネル登録者数の3倍以上の再生数を持つ動画を検索

## 特徴

- 🎯 **バイラル動画の自動検出**: 登録者数に対して異常に多い再生数を持つ動画を発見
- 📊 **詳細な分析指標**: 高評価率、コメント率、エンゲージメント率などを算出
- 🗓️ **期間指定検索**: 投稿日で絞り込み可能
- 📁 **複数の出力形式**: テーブル表示、詳細表示、CSV、JSON
- ⚡ **高速検索**: YouTube Data API v3を使用

## 出力データ

以下の情報を取得できます：

### 動画情報
- 動画URL
- サムネイルURL
- タイトル
- 再生数
- 高評価数
- 高評価率
- コメント数
- コメント率
- 公開日
- 動画の長さ

### チャンネル情報
- チャンネル名
- チャンネルURL
- 登録者数
- 総動画数
- チャンネル開設日

### 分析指標
- **登録者倍率**: 登録者数の何倍の再生数か
- **高評価率**: 高評価数 ÷ 再生数
- **コメント率**: コメント数 ÷ 再生数
- **エンゲージメント率**: (高評価数 + コメント数) ÷ 再生数

## セットアップ

### 1. YouTube API キーの取得

1. [Google Cloud Console](https://console.cloud.google.com/) にアクセス
2. プロジェクトを作成（または既存のプロジェクトを選択）
3. 「APIとサービス」→「ライブラリ」で「YouTube Data API v3」を有効化
4. 「APIとサービス」→「認証情報」でAPIキーを作成

### 2. インストール

```bash
# リポジトリをクローン（または移動）
cd youtube_tool

# 依存パッケージをインストール
npm install

# 環境変数を設定
cp .env.example .env
# .envファイルを編集してYOUTUBE_API_KEYを設定
```

### 3. ビルド

```bash
npm run build
```

## 使用方法

### 基本的な検索

```bash
npm run dev -- search -k "料理レシピ"
```

### 期間を指定して検索

```bash
npm run dev -- search -k "プログラミング" -a 2024-01-01 -b 2024-12-31
```

### 倍率の閾値を変更（5倍以上）

```bash
npm run dev -- search -k "ゲーム実況" -t 5
```

### 詳細表示モード

```bash
npm run dev -- search -k "筋トレ" -o detailed
```

### CSV形式でファイルに保存

```bash
npm run dev -- search -k "DIY" -o csv -f results.csv
```

### JSON形式でファイルに保存

```bash
npm run dev -- search -k "ビジネス" -o json -f results.json
```

### 全オプション

```bash
npm run dev -- search \
  -k "検索キーワード" \
  -a 2024-01-01 \              # 開始日（省略可）
  -b 2024-12-31 \              # 終了日（省略可）
  -m 100 \                     # 最大検索数（デフォルト: 50）
  -t 3 \                       # 倍率閾値（デフォルト: 3）
  -o table \                   # 出力形式: table/detailed/csv/json
  -f output.csv                # ファイル保存（省略可）
```

## API制限について

YouTube Data API v3には以下の制限があります：

- **1日あたりのクォータ**: 10,000ユニット（デフォルト）
- **検索API**: 100ユニット/リクエスト
- **動画詳細API**: 1ユニット/リクエスト
- **チャンネル詳細API**: 1ユニット/リクエスト

このツールは1動画あたり約2ユニットを消費するため、1日に約5,000動画まで分析可能です。

## トラブルシューティング

### APIキーエラー

```
❌ エラー: YOUTUBE_API_KEY が設定されていません。
```

→ `.env`ファイルに`YOUTUBE_API_KEY=your_key`を設定してください。

### クォータ超過エラー

```
Error: The request cannot be completed because you have exceeded your quota.
```

→ 翌日まで待つか、Google Cloud Consoleでクォータを増やしてください。
